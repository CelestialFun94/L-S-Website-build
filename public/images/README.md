# Public website images

Add approved, public-facing Love & Sunshine images to this folder.

- Use lowercase, descriptive filenames with hyphens, such as `artist-writing-session.webp`.
- Prefer WebP or AVIF for photographs and SVG for logos or simple artwork.
- Do not place contracts, IDs, private client files, credentials, or unreleased artist material here.
- Compress images before committing them. Aim for under 500 KB when practical.
- Reference an image from the site as `/public/images/filename.webp`.

Files in this folder are public to anyone who knows their website URL.
